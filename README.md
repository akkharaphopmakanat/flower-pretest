# flower-pretest

เว็บแอปจัดดอกไม้ 3D สำหรับลองจัดช่อก่อนทำจริง (Three.js, ไม่ต้อง build)

## Run

```bash
python3 -m http.server 8765
# เปิด http://localhost:8765
```

## Features

- ดอกไม้ 5 ชนิด + ดอกไม้เสริม 2 ชนิด + ใบไม้ 4 ชนิด (เปลี่ยนสีได้)
- ช่อกลม / ช่อแบน
- ห่อกระดาษ 4 ทรง หรือตะกร้า 4 ทรงพร้อมโฟม, ริบบิ้น
- ลากย้ายดอกไม้เอง (ดอกอื่นขยับหลบ), ปรับความสูง/ขนาด
- สุ่มไอเดีย, สรุปรายการ, บันทึกรูป PNG
